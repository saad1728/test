# 🚌 زحمة الباصات • Bus Jam

لعبة ألغاز HTML5 كاملة بنفس فكرة ألعاب "Bus Jam / Bus Out" المشهورة، جاهزة للنشر والربح من الإعلانات.

**جرّبها فوراً:** افتح `index.html` في المتصفح (أو شغّل سيرفر محلي: `npx http-server` ثم افتح الرابط من الجوال أو الكمبيوتر).

---

## 🎮 فكرة اللعبة

- اضغط على أي باص في الزحمة ليتحرك **باتجاه السهم** — إذا كان الطريق مفتوحاً يخرج ويقف في المواقف بالأعلى.
- الركاب الملوّنون يركبون تلقائياً في الباص **المطابق للونهم**.
- إذا امتلأ الباص ينطلق ويفرّغ الموقف.
- تخسر إذا امتلأت المواقف ولا يوجد راكب مطابق — وتقدر تكمل بمشاهدة إعلان!

### المميزات الجاهزة

| الميزة | التفاصيل |
|---|---|
| ♾️ مراحل غير محدودة | توليد تلقائي لمراحل **مضمونة الحل** وصعوبة متدرجة |
| 🔄🧹🧲 ثلاث مساعدات | خلط الباصات، شفط باص، ترتيب الركاب |
| 🪙 عملات ومتجر | اربح عملات واشترِ المساعدات |
| 📺 إعلانات جاهزة | بانر + إعلانات بينية + إعلانات مكافآت |
| 🔊 أصوات | مولّدة بالكود بدون ملفات صوت |
| 🌍 لغتان | عربي (افتراضي) + إنجليزي |
| 💾 حفظ تلقائي | التقدم والعملات محفوظة في المتصفح |
| 📱 PWA | تعمل على الجوال وقابلة للتثبيت |

## 💰 تفعيل الإعلانات الحقيقية (خطوة بخطوة)

اللعبة الآن تعرض **إعلانات تجريبية محاكاة** حتى تضع معرّفك. كل أماكن الإعلانات مربوطة وجاهزة:

- **إعلان بيني (Interstitial):** يظهر بين المراحل.
- **إعلانات مكافآت (Rewarded):** هدية العملات 🎁، موقف إضافي، إكمال بعد الخسارة، الحصول على مساعدات.
- **بانر:** أسفل الشاشة.

### الطريقة الأولى: نشر اللعبة كموقع ويب (الأسهل) — Google AdSense

1. ارفع اللعبة على دومين خاص بك (انظر "النشر" بالأسفل). AdSense يتطلب موقعاً فعلياً.
2. سجّل في [Google AdSense](https://adsense.google.com) وأضف موقعك وانتظر الموافقة.
3. فعّل **H5 Games Ads (Ad Placement API)** من [هنا](https://adsense.google.com/start/h5-games-ads/) — هذه هي خدمة إعلانات الألعاب من قوقل (بينية + مكافآت داخل الألعاب).
4. افتح الملف **`js/ads.js`** وعدّل أول سطور:

```js
const ADS_CONFIG = {
  adsenseClient: 'ca-pub-1234567890123456', // ← معرّف الناشر الخاص بك
  bannerSlot: '1234567890',                  // ← معرّف وحدة البانر (اختياري)
  testAds: true,                             // اجعلها false عند النشر النهائي
};
```

5. جرّب بـ `testAds: true` (تظهر إعلانات قوقل التجريبية)، ثم اجعلها `false` للنشر.

> ⚠️ **مهم:** لا تضغط على إعلاناتك بنفسك أبداً ولا تطلب من أحد الضغط عليها — هذا يؤدي لإغلاق حسابك في AdSense.

### الطريقة الثانية: تطبيق أندرويد على Google Play — AdMob

1. حوّل اللعبة لتطبيق باستخدام [Capacitor](https://capacitorjs.com):
   ```bash
   npm init -y
   npm i @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "Bus Jam" com.yourname.busjam --web-dir .
   npx cap add android
   ```
2. أضف إضافة AdMob مثل [`@capacitor-community/admob`](https://github.com/capacitor-community/admob).
3. في `js/ads.js` استبدل دوال `interstitial` و`rewarded` و`setupBanner` بنداءات إضافة AdMob — أماكن الاستدعاء في اللعبة لن تتغير لأن كل شيء يمر عبر كائن `Ads` الموحّد.
4. أنشئ حساب [AdMob](https://admob.google.com)، وأنشئ وحدات إعلانية (Banner / Interstitial / Rewarded) وضع معرّفاتها.
5. ابنِ التطبيق وارفعه على Google Play (حساب مطوّر بـ 25$ مرة واحدة).

## 🌐 النشر (مجاني)

أسهل خيار: **GitHub Pages**

1. من إعدادات هذا المستودع: Settings ← Pages.
2. اختر Branch: `main` و Folder: `/ (root)` ثم Save.
3. لعبتك ستكون على `https://USERNAME.github.io/REPO/`.

> ملاحظة: AdSense يحتاج غالباً **دومين خاص** (مثل busjam.com بـ ~10$/سنة) — تقدر تربطه بـ GitHub Pages مجاناً من نفس صفحة الإعدادات.

خيارات أخرى: [Netlify](https://netlify.com) / [Vercel](https://vercel.com) / [itch.io](https://itch.io) (مجتمع ألعاب جاهز) / [CrazyGames](https://developer.crazygames.com) و [Poki](https://developers.poki.com) (منصات ألعاب تتقاسم معك الأرباح بدون ما تحتاج AdSense أصلاً — قدّم لعبتك لهم!).

## 🗂️ بنية المشروع

```
index.html      واجهة اللعبة (شاشة البداية + شاشة اللعب)
css/style.css   كل التنسيقات
js/levels.js    توليد المراحل (خوارزمية تضمن أن كل مرحلة قابلة للحل)
js/game.js      محرك اللعبة (الرسم، اللمس، الركاب، الفوز/الخسارة، المساعدات)
js/ads.js       طبقة الإعلانات — عدّل ADS_CONFIG هنا فقط
js/audio.js     المؤثرات الصوتية (WebAudio)
manifest.json   إعدادات PWA
icon.svg        أيقونة اللعبة
```

### تخصيص سريع

- **اسم اللعبة:** غيّره في `index.html` (العنوان) و `manifest.json` و `js/game.js` (قاموس `T`).
- **الألوان:** مصفوفة `PALETTE` في `js/levels.js`.
- **الصعوبة:** دالة `levelConfig` في `js/levels.js` (حجم الشبكة، عدد الألوان، نسبة الامتلاء).
- **أسعار المساعدات والمكافآت:** ثوابت `BOOSTER_COST` و`CONTINUE_COST` و`GIFT_COINS` في `js/game.js`.
